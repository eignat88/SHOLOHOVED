# Многофункциональное приложение для обработки текста

## Описание

Приложение предназначено для обработки текстовых файлов и включает в себя широкий набор инструментов для работы с текстом. Интерфейс программы представлен в виде вкладок, каждая из которых отвечает за определенную функциональность.

## Системные требования

- Python 3.6 или выше
- Установленные библиотеки:
  - tkinter (для графического интерфейса)
  - nltk (для обработки естественного языка)
  - beautifulsoup4 (для работы с XML)
  - docx2txt и python-docx (для работы с файлами DOCX)
  - matplotlib и numpy (для визуализации)
  - wordcloud (для создания облака слов)
  - tqdm (для индикации прогресса)

## Запуск приложения

Для запуска приложения используйте команду:

```
python combined_text_processor.py
```

## Функциональные возможности

### Конвертация в FB2

Вкладка позволяет конвертировать текстовые файлы (TXT) и документы Word (DOCX) в формат FB2 (FictionBook 2), который широко используется для электронных книг.

**Использование:**
1. Выберите тип конвертации (TXT → FB2 или DOCX → FB2)
2. Нажмите кнопку "Обзор" и выберите исходный файл
3. Нажмите "Конвертировать"
4. После завершения конвертации вы можете открыть результат

### Расчет времени чтения

Данная вкладка позволяет рассчитать примерное время, необходимое для прочтения текстового файла.

**Использование:**
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. Установите скорость чтения (слов в минуту)
3. Нажмите "Рассчитать время чтения"
4. Приложение выведет количество слов в тексте и оценку времени чтения

### Конвертация DOCX в TXT

Эта вкладка предназначена для преобразования документов Microsoft Word (DOCX) в текстовый формат (TXT).

**Использование:**
1. Нажмите кнопку "Обзор" и выберите файл DOCX
2. Нажмите "Конвертировать DOCX в TXT"
3. После завершения конвертации вы можете открыть результат

### Анализ текста

Вкладка предлагает два типа анализа текста:

#### Поиск слов
- Позволяет искать все слова в тексте, содержащие указанную подстроку
- Результаты можно скопировать в буфер обмена

**Использование:**
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. Введите слово или часть слова для поиска
3. Нажмите "Найти"
4. Результаты поиска отобразятся в поле ниже

#### Анализ по списку слов
- Позволяет найти в тексте предложения, содержащие слова из заданного списка

**Использование:**
1. Выберите файл со списком слов (каждое слово должно быть на отдельной строке)
2. Выберите текстовый файл для анализа
3. Нажмите "Запустить анализ"
4. Результаты будут сохранены в текстовый файл

### Разделение текста

Данная вкладка предназначена для разделения большого текстового файла на несколько меньших файлов по определенному шаблону.

**Использование:**
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. Выберите шаблон для разделения:
   - По 4-значным числам (например, разделение глав, обозначенных номерами)
   - По пользовательскому шаблону (укажите свой шаблон)
3. Нажмите "Разделить текст"
4. После завершения операции вы можете открыть папку с результатами

### Статистика текста

Вкладка предоставляет инструменты для статистического анализа текста и визуализации:

#### Частотный анализ
Позволяет проанализировать частоту встречаемости слов в тексте.

**Использование:**
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. Настройте параметры анализа:
   - Минимальная длина слова (по умолчанию 3)
   - Количество слов в топе (по умолчанию 20)
   - Опция исключения стоп-слов (предлогов, союзов и т.д.)
3. Нажмите "Выполнить анализ"
4. Результаты будут представлены в виде таблицы и гистограммы
5. Используйте панель инструментов под графиком для масштабирования и сохранения
6. При необходимости сохраните результаты в текстовый файл

#### Облако слов
Создает визуальное представление текста в виде облака слов, где размер слова соответствует частоте его употребления.

**Использование:**
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. Настройте параметры:
   - Минимальная длина слова
   - Максимальное количество слов
   - Цветовая схема
   - Размеры облака (ширина и высота)
   - Опция исключения стоп-слов
3. Нажмите "Создать облако слов"
4. Используйте панель инструментов для масштабирования и навигации
5. При необходимости сохраните изображение

## Решение проблем

### Проблемы с кодировкой
- Приложение использует кодировку UTF-8 для работы с файлами
- Если в тексте отображаются неправильные символы, убедитесь, что исходный файл сохранен в кодировке UTF-8

### Ошибки при работе с DOCX
- Убедитесь, что установлены библиотеки docx2txt и python-docx
- Проверьте, что файл не поврежден и имеет действительный формат DOCX

### Проблемы с генерацией графиков
- Требуется установка библиотек matplotlib, numpy и wordcloud
- При больших текстах может потребоваться дополнительное время для обработки

1. ОБЩИЕ СВЕДЕНИЯ
------------------

Многофункциональное приложение для обработки текста - это инструмент с графическим интерфейсом, предназначенный для работы с текстовыми файлами различных форматов. Приложение поддерживает русский язык и предоставляет широкие возможности для обработки, анализа и конвертации текстов.

2. ЗАПУСК ПРИЛОЖЕНИЯ
------------------

Для запуска приложения необходимо выполнить файл combined_text_processor.py
командой: python combined_text_processor.py

После запуска откроется главное окно приложения с вкладками, каждая из которых отвечает за определенную функцию.

3. РАБОТА С ФУНКЦИЯМИ ПРИЛОЖЕНИЯ
-------------------------------

3.1. КОНВЕРТАЦИЯ В FB2
---------------------

Данная вкладка позволяет конвертировать текстовые файлы и документы Word в формат FB2 (FictionBook 2), который используется для электронных книг.

Порядок действий:
1. Выберите тип конвертации с помощью переключателя:
   - TXT в FB2
   - DOCX в FB2
2. Нажмите кнопку "Обзор" и выберите исходный файл
3. Нажмите кнопку "Конвертировать"
4. После успешной конвертации появится диалоговое окно с вопросом об открытии файла
5. При согласии файл будет открыт в программе, ассоциированной с форматом FB2

3.2. РАСЧЕТ ВРЕМЕНИ ЧТЕНИЯ
-------------------------

Эта вкладка позволяет оценить время, необходимое для прочтения текстового файла.

Порядок действий:
1. Нажмите кнопку "Обзор" и выберите текстовый файл для анализа
2. Установите скорость чтения в поле "Скорость чтения (слов в минуту)"
   По умолчанию установлено значение 200 слов в минуту
3. Нажмите кнопку "Рассчитать время чтения"
4. В разделе "Результаты" будет отображена следующая информация:
   - Общее количество слов в тексте
   - Оценка времени чтения (минуты и секунды)

3.3. КОНВЕРТАЦИЯ DOCX В TXT
--------------------------

Данная вкладка предназначена для преобразования документов Microsoft Word в текстовый формат.

Порядок действий:
1. Нажмите кнопку "Обзор" и выберите файл формата DOCX
2. Нажмите кнопку "Конвертировать DOCX в TXT"
3. После успешной конвертации появится диалоговое окно с вопросом об открытии файла
4. При согласии файл будет открыт в текстовом редакторе

3.4. АНАЛИЗ ТЕКСТА
----------------

Вкладка "Анализ текста" содержит две подвкладки:

а) Поиск слов
Позволяет найти в тексте все слова, содержащие указанную подстроку.

Порядок действий:
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. В поле ввода укажите слово или часть слова для поиска
3. Нажмите кнопку "Найти"
4. В поле "Результаты поиска" будут отображены все найденные слова
5. При необходимости можно скопировать результаты в буфер обмена кнопкой "Копировать результаты"
6. Для нового поиска можно очистить поля кнопкой "Сброс"

б) Анализ по списку слов
Позволяет найти в тексте предложения, содержащие слова из заданного списка.

Порядок действий:
1. В поле "Файл со списком слов" выберите текстовый файл, содержащий список слов
   (каждое слово должно быть на отдельной строке)
2. В поле "Файл анализа" выберите текстовый файл, который нужно проанализировать
3. Нажмите кнопку "Запустить анализ"
4. Результаты анализа будут сохранены в текстовый файл
5. По завершении анализа появится диалоговое окно с вопросом об открытии результатов

3.5. РАЗДЕЛЕНИЕ ТЕКСТА
--------------------

Эта вкладка предназначена для разделения большого текстового файла на несколько меньших по определенному шаблону.

Порядок действий:
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. Выберите шаблон для разделения:
   - По 4-значным числам (например, главы, обозначенные номерами)
   - По шаблону (укажите собственный шаблон в поле ввода)
3. Нажмите кнопку "Разделить текст"
4. После завершения процесса в поле статуса будет показано количество созданных файлов
5. При согласии открыть папку с результатами будет запущен проводник с соответствующей директорией

3.6. СТАТИСТИКА ТЕКСТА
--------------------

Вкладка "Статистика текста" содержит две подвкладки:

а) Частотный анализ
Анализирует частоту употребления слов в тексте и представляет результаты в виде таблицы и гистограммы.

Порядок действий:
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. Настройте параметры анализа:
   - Минимальная длина слова (по умолчанию 3 символа)
   - Количество слов в топе (по умолчанию 20 слов)
   - Включите или выключите опцию "Исключить стоп-слова"
3. Нажмите кнопку "Выполнить анализ"
4. Результаты будут представлены в виде:
   - Таблицы со словами, их частотой и процентным соотношением
   - Гистограммы для наиболее частых слов
5. Используйте панель инструментов под графиком для:
   - Увеличения и уменьшения масштаба
   - Перемещения по графику
   - Сохранения графика как изображения
6. При необходимости сохраните все результаты анализа в текстовый файл кнопкой "Сохранить результаты"

б) Облако слов
Создает визуальное представление текста в виде облака слов, где размер слова соответствует частоте его употребления.

Порядок действий:
1. Нажмите кнопку "Обзор" и выберите текстовый файл
2. Настройте параметры облака:
   - Минимальная длина слова (по умолчанию 3 символа)
   - Максимальное количество слов (по умолчанию 200)
   - Цветовая схема (выберите из списка)
   - Ширина облака (пиксели)
   - Высота облака (пиксели)
   - Включите или выключите опцию "Исключить стоп-слова"
3. Нажмите кнопку "Создать облако слов"
4. После генерации облако слов отобразится на экране
5. Используйте панель инструментов для:
   - Увеличения и уменьшения масштаба
   - Перемещения по изображению
   - Настройки параметров просмотра
6. Для сохранения облака слов нажмите кнопку "Сохранить изображение"
   или используйте соответствующую кнопку на панели инструментов

4. РЕШЕНИЕ ТИПИЧНЫХ ПРОБЛЕМ
--------------------------

• Если при запуске возникают ошибки, проверьте, установлены ли все необходимые библиотеки:
  nltk, beautifulsoup4, docx2txt, python-docx, matplotlib, numpy, wordcloud, tqdm
  
• При проблемах с отображением текста убедитесь, что исходные файлы сохранены в кодировке UTF-8

• При работе с большими файлами время обработки может увеличиваться

• Если изображения облака слов или графики отображаются некорректно, попробуйте изменить размер окна приложения

• При ошибках конвертации DOCX-файлов убедитесь, что файл не поврежден и является действительным документом Word
